# Agentic AI Dataset Hub

دليل تعليمي عربي ومكتبة مصادر. جميع حالات أهلية البيانات إرشادية وتحتاج مراجعة الحقوق والمصادر الأصلية.

## تشغيل
```bash
npm install
npm run dev
npm test
npm run build
```

## Cloudflare Pages
ارفع المستودع إلى GitHub ثم أنشئ مشروع Pages من Workers & Pages واختر المستودع. اختر الفرع main وأمر البناء `npm run build` ومجلد المخرجات `dist`. إعداد Vite هو الافتراضي. لا يتطلب الموقع قاعدة بيانات أو أسرار. يستخدم localStorage للمفضلة والتقدم. تعتمد المسارات على SPA fallback الافتراضي ولا يحتاج المشروع ملف redirects.

روابط المصادر مقدمة في ملف الطلب؛ لم يتم التحقق من صلاحيتها أو تراخيصها وقت الإنشاء. لا تستخدم بيانات اختبارات محمية للتدريب دون مراجعة.
